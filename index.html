本机优先

你的会话，由本机 Codex 处理。

CloudCodex 复用本机 Codex 的登录、模型和配置，不要求填写新的 API Key。远程控制默认关闭，只有主动开启并完成配对后才会连接远程服务。

✓无需额外填写 API Key
✓远程控制由用户主动开启
✓关闭时不领取或执行远程任务
✓原生 macOS 应用，不含网页统计脚本
开始使用

三步，回到你的 Codex 工作现场。

下载安装包下载并解压 CloudCodex，将应用拖入“应用程序”文件夹。
确认 Codex 已登录需要已安装并登录 ChatGPT/Codex 桌面版，或可用的 Codex CLI。
打开 CloudCodex应用会连接本机 Codex，并加载已有的工作区与会话。
